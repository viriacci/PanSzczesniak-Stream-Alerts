# Pan Szczesniak Stream Alerts

Alerty, nagrody Twitch, kreator scen oraz statystyki transmisji w jednej lokalnej aplikacji dla Windows i OBS Studio.

## PSSA 2.0

**Aktualne wydanie testowe: 2.0.0 RC.22.**

[**Pobierz PSSA 2.0 RC.22**](https://github.com/viriacci/PanSzczesniak-Stream-Alerts/releases/tag/v2.0.0-rc.22) · [Kod źródłowy v2 i instrukcja](https://github.com/viriacci/PanSzczesniak-Stream-Alerts/tree/develop/v2) · [Zgłoś błąd](https://github.com/viriacci/PanSzczesniak-Stream-Alerts/issues)

- Alerty Twitch i nagrody za punkty kanału.
- Edytor wielowarstwowych scen, animacji, tekstu i multimediów.
- Kolejka, historia, profile i biblioteka zasobów.
- Dashboard oraz analityka transmisji.
- Integracja OBS, natywny Control Dock i opcjonalny Agent.
- Skórki, kopie zapasowe i tryby wydajności.

Pobierz instalator Windows x64 oraz sprawdź SHA-256 z plikiem dołączonym do wydania. RC.22 nie jest podpisane cyfrowo i pozostaje wydaniem Beta.

## Starsza wersja

Gałąź `main` zawiera starszą aplikację Python. Jej instrukcja instalacji i konfiguracji jest dostępna w [dokumentacji wersji 1.x](docs/LEGACY_PYTHON.md). Rozwój PSSA 2.0 odbywa się na `develop/v2`; migracja gałęzi głównej nastąpi po odbiorze wydania stabilnego.

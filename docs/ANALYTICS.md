# Analityka historyczna
## Zakres i metodologia
Presety 7/14/30/180 dni, własny przedział do 366 dni, kalendarz i heatmapa UTC. Poprzedni okres bezpośrednio poprzedza bieżący i ma tę samą długość. Kanał wybierany według ID z historii lub bieżącego logowania. Filtrowanie źródła i kategorii, trend dzienny, heatmapa, ranking dziesięciu sesji, historia do 200 pozycji w widoku. Czas to przecięcie sesji z zakresem, zakończenie lokalne może być oszacowane przez ostatni odczyt. Dni bez próbek nie są zerami. Średnia lokalna jest średnią z faktycznie zapisanych próbek, nie oficjalnym Twitch Analytics. Szczyt jest maksimum próbek.
Importowane średnie są oddzielne i ważone długością kompletnych sesji w przedziale. Brak surowych próbek oznacza brak trendu/heatmapy dla importu. Kategoria lokalna jest filtrowana według próbek, czas pozostaje czasem całych pasujących sesji (w zakresie); zdarzenia nie mają przypisania do kategorii. Liczniki zdarzeń lokalnych są obserwowane, nie kompletne. Unikatowi rozmówcy to liczba różnych pseudonimów w zakresie. Nie szacujemy przychodów ani unikatowych widzów. Raport nie zawiera tokenów, ustawień ani identyfikatorów rozmówców.
## Import plików
Bez automatycznego pobierania SullyGnome. Wyłącznie legalnie pozyskane pliki w formacie PSSA v1, ręcznie konwertowane ze źródła posiadającego stosowne uprawnienia. Nie ma zweryfikowanego publicznego API SullyGnome; nie scrapować. Import można uruchomić bez logowania do Twitch.
JSON: {"version":1,"sessions":[{"channel":"123","externalId":"stream-1","startedAt":1790812800000,"endedAt":1790816400000,"title":"Example","categoryId":"1","category":"Game","average":12.5,"peak":20,"provenance":"User-provided history"}]}
CSV UTF-8 (BOM dopuszczalny), przecinek, nagłówek dokładnie: channel,externalId,startedAt,endedAt,title,categoryId,category,average,peak,provenance
Czasy Unix ms UTC, ID kanału i kategorii numeryczne tekstowe, categoryId i externalId mogą być puste, brak avg/peak JSON null / CSV pusta komórka. Limit 10000 sesji / 10 MB / 14 dni na sesję; dane z przyszłości i błędne średnie odrzucane. Import atomowy, pomija nakładanie czasów, ten sam start i identyfikator sesji. Późniejsze obserwacje lokalne mają pierwszeństwo nad nakładającym się importem (cała importowana sesja ukryta w raporcie, nie kasowana). Nie próbujemy automatycznie uzupełniać częściowo pokrywających się sesji ani surowych luk ze średnich.
## Eksport
CSV i JSON przez natywny wybór ścieżki. CSV zawiera podsumowania zakończonych pełnych sesji; JSON dodatkowo raport bieżącego i poprzedniego okresu. Eksportowane podsumowania mogą być zaimportowane na innej instalacji, nie są pełnym backupem i nie zachowują surowych eventów/próbek. Pola tekstowe CSV zabezpieczone przed typowymi formułami arkusza. Pełny backup w etapie 10. Brak dodatkowych pakietów npm.

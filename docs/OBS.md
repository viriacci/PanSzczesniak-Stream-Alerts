# Nakładka — etap 3
W Integracjach skopiuj lokalny URL do źródła przeglądarkowego OBS, zalecane 1920x1080. Overlay działa niezależnie od OAuth; test w Alertach zapisuje regułę i emituje zdarzenie.
Serwer 127.0.0.1:18766, losowy trwały sekret w ścieżce, brak LAN, kontrola Host, CSP, tylko dozwolone pliki mediów i sprawdzenie realpath. Nie publikować URL. Transport do przeglądarki: HTTP Server-Sent Events (jednokierunkowy zamiast osobnego WebSocket). Twitch nadal używa WebSocket. Połączenie SSE nie wymaga dodatkowych zależności. Etap 4 wprowadzi kolejkę i kanał potwierdzeń odtwarzania. Teraz kolejne alerty zastępują wcześniejsze; brak gwarancji dostarczenia przy nieobecnym OBS.
Import starego config.json: reguły, przypisania nagród, względne pliki w media/, pozycje, kolory, fonty systemowe, obramowania, animacje, czas i tekst. Nie importuje tokenów ani dowolnych ścieżek źródłowych. Stare pliki pozostają nienaruszone; ostrzeżenia o brakujących plikach. Pełny edytor i dokładna zgodność wizualna w etapie 7.

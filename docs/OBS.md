# Nakładka — etap 3
W Integracjach skopiuj lokalny URL do źródła przeglądarkowego OBS, zalecane 1920x1080. Overlay działa niezależnie od OAuth; test w Alertach zapisuje regułę i emituje zdarzenie.
Serwer 127.0.0.1:18766, losowy trwały sekret w ścieżce, brak LAN, kontrola Host, CSP, tylko dozwolone pliki mediów i sprawdzenie realpath. Nie publikować URL. Transport do przeglądarki: HTTP Server-Sent Events (jednokierunkowy zamiast osobnego WebSocket). Twitch nadal używa WebSocket. Połączenie SSE nie wymaga dodatkowych zależności. Etap 4 wprowadzi kolejkę i kanał potwierdzeń odtwarzania. Teraz kolejne alerty zastępują wcześniejsze; brak gwarancji dostarczenia przy nieobecnym OBS.
Import starego config.json: reguły, przypisania nagród, względne pliki w media/, pozycje, kolory, fonty systemowe, obramowania, animacje, czas i tekst. Nie importuje tokenów ani dowolnych ścieżek źródłowych. Stare pliki pozostają nienaruszone; ostrzeżenia o brakujących plikach. Pełny edytor i dokładna zgodność wizualna w etapie 7.

## Etap 5
OBS 28+ / WebSocket 5, lokalny port 4455 (konfigurowalny), hasło szyfrowane safeStorage. Handshake Hello/Identify, SHA-256 base64, timeouty, ponowne połączenie i polling co 5 s. Pobieranie scen, GetStats, GetStreamStatus, GetRecordStatus, zmiana sceny programu i refreshnocache tylko źródeł browser_source o dokładnym URL PSSA. Nie uruchamia ani nie zatrzymuje transmisji OBS. Brak danych oznaczony jako brak, bez wartości zastępczych.
PSSA Agent: osobny bezokienkowy proces Electron, port 18767, trwały losowy klucz lokalny w pliku agent.key (uprawnienia katalogu użytkownika), Bearer i kontrola Host/Origin, URL dock z kluczem we fragmencie. Agent nie wymaga otwartego PSSA. Uruchom w Integracjach, opcjonalnie włącz autostart Windows (tylko wersja zainstalowana) i start PSSA po wykryciu obs64.exe. W OBS Panele → Własne panele przeglądarkowe → PSSA Control → wklej adres. Start/stop/restart aplikacji i refresh podłączonych nakładek SSE. Restart jest łagodny; kolejka zachowana. Watchdog ograniczony do procesów uruchamianych przez Agenta, maks. 3 awarie/min; brak automatycznego zabijania zawieszonego lub obcego procesu. Agent nie jest usługą systemową, działa w sesji użytkownika. Nie publikować linków z kluczem. Wyłączenie autostartu nie zamyka działającego Agenta.
Testy mock WebSocket, HTTP i kontrolera; realny OBS, Windows autostart, osobny proces i interakcja z dockiem wymagają manualnej weryfikacji. Statystyki historyczne w etapie 6/9.

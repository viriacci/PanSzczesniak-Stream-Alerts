# Live Center — etap 6
## Dane
Twitch Get Streams co 30 s, EventSub stream.online/offline uruchamia dodatkowy odczyt. Twitch ID transmisji + channel_id identyfikują sesję. Błąd API nie zamyka sesji i nie zapisuje 0 widzów; stan unknown. Potwierdzony offline lub nowe ID zamyka poprzednią sesję z czasem ostatniego potwierdzenia (dolne oszacowanie, end_quality=last-seen), nie wymyśla dokładnego końca. Ponowne wykrycie tego samego ID otwiera tę samą sesję. Nie ma danych z okresu wyłączonego PSSA. Odczyty są przybliżone i mogą być opóźnione po stronie Twitcha.
SQLite schema 3: metadane sesji, kategoria każdej próbki, channel_id i pseudonim rozmówcy w stream_events, obs_samples z telemetrią i bitrate. Czasy Unix epoch ms UTC. Średnia to średnia arytmetyczna z próbek, peak to ich maksimum, nie oficjalne Twitch Analytics. Wykres ostatnich 480 próbek, przerwy >90s bez łączenia. Historia pełnych sesji zostaje w bazie.
## Zdarzenia
Zapis niezależny od alertów, filtrów i kolejki. ID EventSub unikalny, przypisanie do sesji po potwierdzeniu zakresu czasowego; zdarzenia po ostatniej próbce mogą pozostać nieprzypisane, zamiast zgadywania. Chat message: liczba i unikatowi rozmówcy, bez tekstu, surowego ID i nazwy użytkownika; lokalny solony hash nie jest pełną anonimizacją. Shared Chat z obcych kanałów odfiltrowany. Liczniki to obserwowane zdarzenia, nie pełna historia; brak subskrypcji, rozłączenie i nieuruchomiony program mogą zaniżać wyniki. Gift suby zliczane według liczby, nie liczby paczek. Punkty z kosztu nagrody w zdarzeniu.
## OBS
Próbki z istniejącego pollingu co 5 s, odrębny odczyt świeżego timestampu, zapis tylko przy potwierdzonej sesji Twitch i aktywnej transmisji OBS. Bitrate kb/s = 8 * delta bytes / delta ms; brak wartości przy pierwszej próbce, reset liczników, zbyt długiej przerwie lub braku OBS. Nie wyliczamy przychodu ani unikatowych widzów.
## Zarządzanie
PATCH channels (tytuł i game_id), Search Categories, POST streams/markers. Scope channel:manage:broadcast dodawany do nowego OAuth, istniejące tokeny bez scope mogą nadal odczytywać dane; ponowne logowanie dla edycji. Bez automatycznej zmiany tytułu lub kategorii, tylko jawny zapis użytkownika. Markery wymagają aktywnej transmisji i warunków Twitcha.

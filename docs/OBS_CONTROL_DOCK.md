# PSSA Control Dock — RC.12
Native Windows x64 OBS plugin, built from the pinned official OBS 31.1.1 plugin template. Plugin source GPL-2.0-or-later. The PSSA application remains a separate process.
Install from PSSA Settings → Dodaj wtyczkę do OBS while OBS is closed. Windows UAC is required for ProgramData. The first build targets OBS 31–33 standard installation; portable mode and compatibility with every OBS release are not yet verified. Restart OBS, open Docks → PSSA Control Dock. Run PSSA once after installing/updating so it records the current executable path. Do not run OBS elevated if launching PSSA from the dock.
The dock opens compact, with four buttons and expandable More. Starts background without renderer, controlled quit, restart, show window. More contains the authoritative global volume/mute, test, overlay reload, source addition to selected preview scene in Studio Mode, current scene otherwise, and optional startup/shutdown settings (both off initially). Source uses the existing browser overlay and reuses matching or managed sources. New sources are 1920×1080 and scaled to canvas. No OBS WebSocket setup is required.
The local named pipe is random per launch with an authenticated 256-bit token in the current user's AppData. Only fixed commands are accepted. No shell or arbitrary file commands. The descriptor is not logged. Elevated OBS cannot launch a user-writable executable.
Acceptance: unit tests authenticate IPC and exercise actual local pipe. Windows CI compiles the DLL and packages it. Actual OBS UI/compatibility and audio routing require OBS runtime smoke testing; a successful compiler build is not evidence that those tests ran.

The expanded area scrolls inside a small dock. CI also exercises real local control while the Electron renderer is destroyed in background mode.

RC.11 discovers running OBS, uninstall/OBS registry keys, standard directories, and Steam libraries, before offering manual file selection. Version parsing uses file/product text and registry metadata, with a confirmation-only version selection if unknown. OBS 31–32 use legacy ProgramData layout, OBS 33 modern layout. No compatibility check bypass for known out-of-range versions.

RC.12: reuse one browser source by reference in multiple scenes; duplicate check only in selected scene. Restart is an authenticated command to Electron (relaunch after graceful quit); dock waits for a different authenticated instance token, has a bounded timeout, and clears lifecycle flags. Settings detects existing plugin via SHA-256 and offers update/reinstall while OBS is closed. Existing QSettings and scene configuration remain untouched.

RC.13: Windows DLL replacement uses a real backup path, SHA-256 checks and stage-specific error codes; CI exercises the exact replacement commands using temporary files. The application updater reads public GitHub Releases, requires the exact versioned x64 setup asset and GitHub SHA-256 digest, verifies downloaded bytes, and requires valid matching Authenticode signer certificates before launching. Unsigned builds require manual execution; OBS must be closed. Existing runtime preferences are retained. Fresh RC installs default to Beta and automatic update checks.

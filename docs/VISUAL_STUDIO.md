# Kreator Alertów
## Model
Scene v1 jest opcjonalnym polem AlertRule (SQLite settings oraz snapshot kolejki, bez zmiany schematu SQL). Rozdzielczość 320–3840 × 180–2160, długość 1–120 s, do 32 warstw. Kolejność tablicy od dołu do góry. Typy: tekst, obraz PNG/JPG/GIF/WebP, MP4/WebM, audio MP3/WAV/OGG/M4A, kształt i proste cząsteczki (24 na warstwę). SVG nie jest jeszcze obsługiwane. Obsługa kodeków i alpha WebM zależy od Chromium/OBS.
Pozycja i rozmiar w procentach, pozycja oznacza środek. Obrót, krycie, tło, obramowanie, font, prostokąt/elipsa. Warstwy mają początek i koniec w ms, animacje wejścia/wyjścia z czasem do 3 s. {alert} w tekstach oznacza wyrenderowany szablon reguły z istniejącymi zmiennymi Twitch. Nie wykonujemy HTML ani własnych skryptów użytkownika.
## Edycja
Lista warstw, zmiana kolejności, duplikowanie, usuwanie, blokada i widoczność. Przeciąganie i uchwyt skalowania względem środka; prowadnice środka i snap 2%, właściwości numeryczne. Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y; do 50 stanów undo. Oś czasu pokazuje zakresy, pozwala wybrać pozycję odtwarzania; zakres zmieniany polami początek/koniec. Nie jest to jeszcze nieliniowy edytor keyframe. Zapis jawny; zmiana alertu albo wyjście z modułu porzuca niezapisane zmiany. Przyszłe usprawnienie: ochrona niezapisanych zmian, autosave szkiców i drag timeline.
## Renderer
src/shared/scene-player.ts: jedna samodzielna funkcja DOM dla React preview i JS nakładki. Zegar requestAnimationFrame, wspólna geometria, skalowanie całej sceny z zachowaniem proporcji, animacje i obsługa mediów. Nakładka zachowuje ACK, volume i cancel. Media tylko z lokalnego serwera z kluczem; CSP desktop dopuszcza media wyłącznie na 127.0.0.1:18766. Brak nowych zależności. Przed zapisem parseScene waliduje model po stronie main. Starsza reguła konwertowana przy renderowaniu; wygląd i timing animacji mogą się nieco różnić od Python i wcześniejszej nakładki. Zapis nowej sceny nie usuwa starego layoutu.
## Weryfikacja
Testy modelu, migracji legacy, zapisu, zmiany długości, serializacji wspólnej funkcji. Smoke Electron rozszerzony o odtworzenie tekstowego alertu w rzeczywistym Chromium (osobne okno nakładki), obserwację tekstu i ACK. Realne OBS/CEF, kodeki, alpha, ergonomia drag/resize i porównanie wizualne wymagają manualnej weryfikacji w audycie B.

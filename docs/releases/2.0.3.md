# PSSA 2.0.3

Aktualizator zapisuje niepodpisany instalator Stable w folderze Pobrane po potwierdzeniu użytkownika, sprawdzeniu SHA256 i oznaczeniu strefy internetowej Windows. Uruchomienie pozostaje ręczne; podpis nieprawidłowy lub niezweryfikowany nadal blokuje instalację. Z poprzednich wersji przejdź na 2.0.3 przez ręczne pobranie oficjalnego instalatora. Zamknij OBS, Agenta i PSSA przed instalacją.

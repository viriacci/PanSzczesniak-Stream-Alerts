## Kreator alertów

- Delete usuwa zaznaczoną niezablokowaną warstwę; Ctrl+Z przywraca ją. Pola tekstowe i otwarte dialogi są chronione.
- Krawędzie zmieniają rozmiar w jednej osi; Alt przycina, Ctrl skaluje od środka. Dyskretne uchwyty i właściwe kursory.

## Aktualizacje

- Po pobraniu i sprawdzeniu SHA256 instalator Beta może być uruchomiony przez PSSA po wyraźnej zgodzie na niepodpisany plik. Nieprawidłowe lub niezweryfikowane podpisy blokują automatyczne uruchomienie. Windows może wyświetlić ostrzeżenie lub UAC. RC.17 nadal wymaga ręcznego uruchomienia setupu przy pierwszej aktualizacji do RC.18.

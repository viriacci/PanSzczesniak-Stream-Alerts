# PSSA 2.0.0 RC.21 (Beta)

- Usunięto 28 wskazanych opisów z interfejsu, zachowując instrukcję i istotne komunikaty operacyjne.
- Zmienne w edycji reguł alertów i nagród oraz w menu kreatora mają krótkie kontekstowe objaśnienia. Dostępne zmienne odpowiadają rzeczywistym zdarzeniom Twitch. Istniejące szablony, sceny i tokeny pozostają bez zmian.
- Ważne informacje przeniesiono do instrukcji, m.in. OAuth, prywatność kopii i diagnostyki.
- Dodano testy kontekstowych zmiennych; baseline aktualizacji RC.20.

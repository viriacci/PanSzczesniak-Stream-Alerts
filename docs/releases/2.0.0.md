# PSSA 2.0.0

Pierwsze stabilne wydanie PSSA drugiej generacji.

## Funkcje

- Alerty Twitch i nagrody za punkty kanału z własnym tekstem, dźwiękiem, obrazami, GIF-ami i wideo.
- Kreator Alertów: warstwy, oś czasu, animacje, keyframe'y, zmienne, kadrowanie i szablony.
- Kolejka z priorytetami, historią, pauzą, wyciszeniem i powtórkami.
- Biblioteka mediów, profile alertów i warianty.
- Dashboard, historia transmisji, porównania okresów oraz import i eksport statystyk.
- Integracja OBS, natywny PSSA Control Dock i opcjonalny Agent.
- Tryby Studio, Streaming i Background, trzy skórki, pomoc oraz kopie zapasowe.

Od RC.22 ograniczono zbędne odczyty SQLite i operacje renderowania, usprawniono import multimediów oraz poprawiono autoryzację Twitch i kontrolę aktualizacji.

## Instalacja i aktualizacja

Windows x64. Pobierz PSSA-Setup-2.0.0-x64.exe i zweryfikuj SHA256SUMS.txt. Instalator nie jest podpisany cyfrowo; uruchom go ręcznie po zamknięciu PSSA, Agenta i OBS. Dane instalacji v2 zostają zachowane. Przed aktualizacją wykonaj kopię zapasową.

Wydanie przechodzi automatyczne testy Windows przed publikacją. Testy na wszystkich konfiguracjach OBS, wielogodzinne transmisje i pełny ręczny audyt pozostają otwarte. Skorzystaj z GitHub Issues w razie problemów.

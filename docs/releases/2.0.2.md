# PSSA 2.0.2

- Control Dock akceptuje aktualny port nakładki i przeładowuje źródła OBS również bez połączonego klienta. Źródła utworzone przez dock otrzymują aktualny adres. Przy dodaniu istniejącego ukrytego źródła zostaje ono uaktywnione.
- Pauza, wznowienie i wyciszenie kolejki dostępne na górze zakładki. Dock pokazuje port i stan połączenia nakładki.
- Iskry instalatora lekko drżą podczas pięciosekundowego postoju animacji.

## Aktualizacja

Zamknij PSSA, Agenta i OBS. Pobierz i uruchom instalator ręcznie (brak podpisu cyfrowego). Po instalacji zaktualizuj PSSA Control Dock w ustawieniach programu przy zamkniętym OBS, uruchom OBS ponownie i odśwież nakładkę. Jeśli źródło zostało dodane ręcznie, porównaj jego adres z Konfiguracją PSSA. Dane użytkownika pozostają w lokalnym profilu Windows.

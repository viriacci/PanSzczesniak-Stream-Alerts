## Aktualizator

- Przycisk „Aktualizuj PSSA” bezpośrednio w ustawieniach po wykryciu wydania.
- Natychmiastowa synchronizacja głównego banera po ręcznym sprawdzeniu.
- Test interfejsu aktualizacji bez pobierania fikcyjnego instalatora.

Wydanie Beta. Instalatory bez zweryfikowanego podpisu nadal wymagają ręcznego uruchomienia po pobraniu.

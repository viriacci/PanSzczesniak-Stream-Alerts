# RC.7 — nawigacja, onboarding i Twitch
Układ tymczasowy: istniejące grupy jako punkt wyjścia. Ustawienia > Ukryj zakładki; koło zębate i Ctrl+, zawsze dostępne. Edytuj menu: przeciągaj kategorie i zakładki, upuszczaj na nagłówkach lub między elementami; maks. 2 poziomy kategorii, 45 węzłów, wszystkie strony zachowane dokładnie raz. Zwijanie i nazwy zapisane w layout.v1. Usuń kategorię promuje jej zawartość. Stary układ migruje do domyślnego ukrytego inspektora. Eksport pozostaje, import CSV/JSON usunięty z UI, dane historyczne zachowane. Migracja PSSA 1.x tylko na dole Integracji. OBS WebSocket przemianowany, zaawansowane funkcje zwinięte.
## Logowanie
Zarejestrować jedną aplikację PSSA typu Public na https://dev.twitch.tv/console/apps (2FA na koncie właściciela). Ustawić publiczny Client ID w GitHub Settings > Secrets and variables > Actions > Variables jako PSSA_TWITCH_CLIENT_ID. Nie tworzyć ani nie wklejać Client Secret. Build wstrzykuje jedynie publiczny identyfikator do main. Bez niego uproszczone logowanie nieaktywne; własny Client ID/Secret w zaawansowanych jako kompatybilność. Device Code Grant: otwiera tylko oficjalny https://www.twitch.tv/activate, wyświetla kod, odpytywanie zgodnie z interval/slow_down, anulowanie przez AbortController, tokeny w DPAPI, odświeżanie bez secret. Istniejące sesje pozostają działające. Publiczne refresh tokeny są rotowane i mogą wygasnąć; ponowne logowanie wymagane. Dokumentacja https://dev.twitch.tv/docs/authentication/getting-tokens-oauth/ . Testy mock; realny Twitch wymaga rejestracji.
